**Summary:** Can a free Forge app later move to Paid via Atlassian on the same listing?

Hello,

I am preparing to list my first Forge app for Jira Cloud ("FRIDAY Flow", app id
ari:cloud:ecosystem::app/360ae8cc-ab00-48b0-9d21-55416fc94182). Before choosing the payment model,
I need to know which changes are possible after the app is published.

1. If I publish the app as **Free**, can I later change the same listing to **Paid via Atlassian**?
   If yes, what happens to existing installations (do customers have to approve a new major version,
   and do they start paying immediately or after a trial)?
2. If I publish it as **Paid via Atlassian**, can I later change it to **Free** on the same listing?
3. If I publish it as **Paid via Atlassian**, can I later enable **app editions** (Standard and Advanced)
   on the same listing, to sell extra features in the Advanced edition?
4. The manifest currently has `licensing.enabled: true`. If I publish as Free, must I set it to false?

The "Pricing, payment, and billing" page and the "I can't change my app's payment model" article
seem to disagree on question 1, so I would like a confirmation before I publish.
